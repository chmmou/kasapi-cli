## kasapi-cli ddnsusers add

Create a DDNS user (add_ddnsuser; the login is generated by KAS)

### Synopsis

Create a DDNS user via add_ddnsuser. KAS generates the login and the
command prints it on success.

add_ddnsuser only takes the legacy single-IP key (--target-ip); the
dyndns_target_ipv4 / dyndns_target_ipv6 dual-stack pair is reserved
for subsequent update_ddnsuser calls. Passing --dual-stack here still
records the dual-stack policy on the new user (the server echoes the
flag) so the follow-up update can set both ipv4 and ipv6 targets — see
"kasapi-cli ddnsusers update --help".

```
kasapi-cli ddnsusers add --password <pw> --zone <z> --label <l> --target-ip <ip> --comment <text> [--dual-stack] [flags]
```

### Options

```
      --comment string     user comment / label (required)
      --dual-stack         flag the user as dual-stack capable (Y); pair with subsequent update_ddnsuser --target-ipv4/--target-ipv6
  -h, --help               help for add
      --label string       host label below the zone (required)
      --password string    DDNS password (required)
      --target-ip string   legacy single-IP target (required; dual-stack ipv4/ipv6 update later)
      --zone string        DNS zone the record lives under (required)
```
